# 玛丽苏壁纸配置助手

## [点这里下载配置助手](https://github.com/Lilinz304/wallpaper-setup/releases/latest/download/WallpaperSetup.zip)

1. 解压下载的压缩包。
2. 打开文件夹，双击 **WallpaperSetup**。
3. 点“开始配置”，照着提示操作。想要歌词，就勾第三项。
4. 在网易云放一首歌，试试壁纸上的按钮。

如果提示“继续绑定”，按包里的“照着点就行-操作流程”操作。
